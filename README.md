# Controlling Time: Recap of Sessions 1 to 6

Big History of Ideas and Innovation, IE University. Group presentation (Session 26) by Rafael, Amalia, Erik and Kareem.

Open the site and present with the keyboard:

- Right / left arrow: next / previous slide
- F: fullscreen
- On a "Recap time" slide: Space spins the wheel, K shows the key points, N opens the class list

The class list (first name and surname initial) is built in. Press N to change it; changes stay only in that browser.
